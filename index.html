O que é HTML?

Definição de HTML

HTML significa Linguagem de Marcação de Hipertexto.

Não é linguagem de programação, é de MARCAÇÃO. Ela estrutura a página, não faz lógica.

Criada por Tim Berners-Lee em 1991. Hoje estamos no HTML5.

Exemplo de fórmula química na web: Água é H2O e carbono é CO2(usa-se a tag sub)

Exemplo de expoente: 210 = 1024(usa-se a tag sup)

Curiosidade - tag aside

Aside é para conteúdo lateral, relacionado mas não principal. Ex: curiosidades, propagandas, leia também.

Você sabia que o HTML tem mais de 100 tags?

Paisagem - Exemplo de Imagens

Tag div: caixa genérica sem semântica, usada só para agrupar e organizar com CSS. Diferente de section/article que tem significado.

Tag img

img insere imagem. Atributos: src = caminho da imagem, alt = texto alternativo para acessibilidade/SEO e quando a imagem não carrega, width e height = tamanho. Se colocar só um, o outro se ajusta proporcionalmente.

Tag picture e source

picture: cria imagens responsivas. source: especifica múltiplas versões da imagem. media: define para qual tamanho de tela cada imagem deve aparecer. Benefício: carrega imagem leve no celular e pesada no PC.

Tag a

a = anchor, cria hiperlink. href = destino. target=_blank abre em nova aba. title cria tooltip ao passar o mouse.

Tags de Estrutura Semântica - Módulo 2

header: cabeçalho da página ou de uma seção. Pode ter logo e título.

nav: área de navegação, menu principal.

main: conteúdo principal da página. Só pode ter um por página.

section: seção temática, agrupa conteúdo relacionado com um tema. Ex: seção de notícias.

article: conteúdo independente e autocontido. Ex: post de blog, notícia. Pode ser distribuído sozinho.

aside: conteúdo lateral, tangencial.

footer: rodapé da página ou de uma seção. Tem copyright, contato.

div: divisor genérico, sem semântica. Só para agrupar.

h1: heading 1, título principal, mais importante para SEO. Só 1 por página idealmente. Vai até h6.

hr: horizontal rule, linha horizontal que separa conteúdos tematicamente.

abbr: abreviatura. Atributo title explica o significado completo.

sub: subscrito, texto embaixo. Ex: H2O

sup: sobrescrito, texto em cima. Ex: 2²

meta: metadados no head, informações para navegador/buscador. Ex: charset, description, keywords.

title: título que aparece na aba do navegador, muito importante para SEO.

Tags de Listas - Módulo 4

ul: unordered list, lista não ordenada com bolinhas.

ol: ordered list, lista ordenada numerada. Atributo reversed inverte a contagem para decrescente.

li: list item, cada item da lista.

dl: definition list, lista de definições.

dt: definition term, termo que está sendo definido.

dd: definition description, definição detalhada do termo.

Tags de Tabela - Módulo 4

table: cria tabela.

tr: table row, uma linha da tabela.

th: table header, célula de cabeçalho, fica em negrito e centralizado.

td: table data, célula de dados normal.

cellpadding: atributo que controla espaçamento interno da célula.

cellspacing: atributo que controla espaço entre as células.

Tag O que é Exemplo
tr Table Row - linha Uma linha horizontal
th Table Header - cabeçalho Título da coluna
td Table Data - dado Conteúdo normal

Tags de Formulário - Módulo 4

form: envolve todos os campos de formulário.

input: campo de entrada. type=text, radio, checkbox, submit etc.

select: caixa de seleção dropdown. Atributo multiple permite selecionar vários segurando Ctrl.

option: cada opção dentro do select. Atributo selected
